# Учёт времени по задачам

Практическая работа к лекции 5 «Этапы разработки программного продукта». Модуль подключается к менеджеру задач, измеряет продолжительность рабочих сеансов и формирует сводный отчёт.

## Запуск в VS Code

Откройте папку проекта в VS Code и выполните в терминале `python main.py`. Требуется Python 3.10 или новее. Используется только стандартная библиотека.

Введите команды по очереди. Между запуском и остановкой таймера можно запросить промежуточный отчёт.

```text
add Разработать модуль
start 1
report
stop 1
report
exit
```

Повторный старт после остановки открывает новый сеанс. Время всех сеансов одной задачи суммируется. Отчёт включает задачи без сеансов, показывает текущие накопленные секунды и состояние таймера. Итоговая строка суммирует время всех задач, включая пересекающиеся интервалы. Задачи и результаты демонстрации хранятся в памяти до выхода.

## Подключение к TaskManager из лекции

Передайте существующий экземпляр менеджера в `TimeTracker`. Модуль обращается к словарю `manager.tasks` по идентификатору и читает название из `task.title`. Созданные после подключения задачи сразу доступны. В файле `task_manager.py` приведена минимальная реализация этого интерфейса для запуска примера.

```python
from time_tracker import TimeTracker

tracker = TimeTracker(manager)
tracker.start(task.task_id)
# Здесь выполняется работа по задаче.
seconds = tracker.stop(task.task_id)
report = tracker.report()
```

Метод `total(task_id)` возвращает время в секундах с учётом текущего сеанса. Для измерений используются монотонные часы. Неизвестный идентификатор, повторный старт активного таймера и остановка неактивного таймера вызывают `ValueError`.

## Проверка

В терминале выполните `python -m unittest -v`. Тесты используют управляемые часы и проверяют накопление времени, исключение пауз, операции с ошибками и отчёт по нескольким задачам.
